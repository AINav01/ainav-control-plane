# AINav — Business model (one page)
### August 20, 2026 · Full model: `BUSINESS_MODEL.md` v4.1

---

## Core lines

| | |
|--|--|
| **Company** | AINav sells authority coverage for privileged agent writes. |
| **Gap** | Agents can change state; security and identity do not dual-admit the write. |
| **Product** | Dual admission and DecisionRecords—before the write runs. |
| **Land** | Prove it in 2–4 weeks for a fixed $28–40k pilot. |
| **Attach** | Stay covered for $40–60k a year. |
| **Champion** | Security shows the estate. AINav decides whether the write may run. |
| **CFO** | Fixed pilot to prove control. Annual fee to keep it. Not seats—coverage. |

**One breath:** Agents can write. Someone must dual-admit the write—with evidence—or it must not run. AINav is that control: prove it in weeks, cover it yearly.

---

## Money

```text
LAND     L1 pilot     $28–40k fixed · 2–4 weeks · dual + DecisionRecord
ATTACH   P-ADM        $40–60k / year · stay covered        ← the product
EXPAND   U-DUAL / SoR / L2 · only after proof · new orders
```

Example year-1 logo: ~$115k (pilot + annual + dual pack).

---

## When it is required

- Agent has a **write** tool (pay, post, mint, change authority)
- Audit asks who approved agent-initiated changes
- Policy needs **four-eyes** on high-blast verbs
- Security/identity are in place; the **write** is still open

**Do not sell** if agents only draft text.

---

## Vs other paths

| Path | Result |
|------|--------|
| Soft approve clicks | No hash lock; replay still works |
| Build it inside | Quarters of open risk |
| Security or identity alone | Estate known; write still unadmitted |
| **AINav** | Proof in weeks; coverage by the year |

---

## Hard rules

FIRST_OFFER only · $25–40k band · no fail-open discounts · one pilot at a time · L1 is not ARR · attach within 90 days of a green pilot
