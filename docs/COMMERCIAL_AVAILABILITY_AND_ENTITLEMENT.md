# Commercial availability & entitlement

**Spine:** L1 prove → P-ADM cover → packs deepen  
**Rule:** Entitlement follows paid SKU. No full-repo default. No production claims without matching gates.

## Availability matrix

| Offering | Available to | Gate | Delivery |
|----------|--------------|------|----------|
| Public pin / health | Anyone | Ops healthy | HTTPS |
| L1-FIX / SALES / FULL | Signed pilot SOW | Verb lock | Fixtures + kit + readout |
| P-ADM | After kit PASS | Attach ≤90 days target | Coverage + support + releases |
| U-DUAL | P-ADM path | Dual exercised in pilot | Policy + roles + tests |
| P-REC / U-SIEM / P-DEP | P-ADM customer | Named need | Export / sink / deploy Actions |
| U-SOR-* | Named SoR + sandbox | Connector SOW | Private adapter |
| L2 | Coverage clear | One prod verb | Prod admit path |
| Partner kit | Approved partner | NDA + agreement | Talk tracks + forms |

**Not on shelf:** unlimited verbs, fail-open modes, IdP/inventory SKUs, whole monorepo clone.

## Library & repository access

| Asset | Access |
|-------|--------|
| Release artifacts | Versioned packages + pinned Lua SHA |
| Fixture packs | Purchased verb classes |
| Connector code | Purchased U-SOR only |
| Full monorepo | **Not** default |

Controls: org accounts, entitlement → modules/SHAs, SHA pin in app config, no SCRIPT FLUSH, secrets never in Lua/public pin.
