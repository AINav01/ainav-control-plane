## 2. Must-have logic

### Without AINav

An agent can propose a privileged Action.  
Someone may click “approve” in a ticket.  
The write can still be **mutated, replayed, or single-person**.  
Afterward, Audit asks *who admitted this?* and gets a story—not a **DecisionRecord**.

That is **open-loop authority**.

### With AINav

```text
Action → evaluate → dual hold → role tokens (hash-bound, single-use)
      → consume both-or-neither → DecisionRecord → effect
      → replay fails · mutation fails
```

### When it becomes non-optional

| Trigger | Force |
|---------|-------|
| Write tools go live on payment / post / mint / CRM authority | Blast radius is real |
| Audit or exam asks for agent-write approval evidence | Logs ≠ dual admit |
| Policy requires four-eyes on high-blast verbs | Soft HITL fails diligence |
| Near-miss involving agent-initiated change | Board attention |
| Security/identity already purchased | Job A/B done; Job C open |

**If agents only draft text → walk.** Must-have claims require write risk.

### Familiar analogues

| You already fund | AINav is the agent-era form of |
|------------------|--------------------------------|
| Dual control on wires | Dual admission on Actions |
| PAM | Effect admit, not only access |
| Release / change control | Pinned policy + SoR obedience |
| SOX approval evidence | DecisionRecord |

## 3. Value (champion math)

```text
Value ≈ residual risk of unconstrained privileged writes
      + cost of audit without reconstructable admits
      + cost of a multi-quarter internal build
      − (L1 + annual coverage)
```

| Alternative | What you pay | What you still lack |
|-------------|--------------|---------------------|
| Nothing | $0 until failure | Everything |
| Soft HITL | Low | Hash lock, replay safety, dual tokens |
| OPA + SI / internal | $150–600k+, quarters | Speed; productized dual + pilot exit |
| Zenity / Agent 365 alone | Their ACV | **Admitted writes** |
| **AINav** | **$28–40k then $40–60k/yr** | — |

## 4. Revenue model

### Spine

| Stage | Offer | Price | Purpose |
|-------|-------|-------|---------|
| **Land** | L1-FIX / SALES / FULL | **$28k / $35k / $40k** | Prove dual + DecisionRecord |
| **Attach** | P-ADM | **$40–60k/yr** | **Stay covered** (the product) |
| **Expand** | U-DUAL | $20–35k/yr | Dual depth |
| | P-REC | $15–25k/yr | Audit evidence program |
| | U-SOR-* | Quote | Dynamics / BC production obedience |
| | L2 | $70–100k+ | One live production verb |
| **Scale** | L3+ | — | Only with references |

Optional L0 briefing: $8–15k.

### Land rules

| Rule | Detail |
|------|--------|
| Catalog | **FIRST_OFFER only** for 90 days |
| Band | **$25–40k** hard |
| Discount | Max **10%** + written scope **cut** (never fail-open) |
| Kill | >4 weeks or “build us a platform” |
| Exit | Non-author reconstructs DecisionRecord; replay fails |
| Cash | 50% kickoff / 50% readout (100% kickoff if under $30k) |

### Attach rules (continuity, not upsell theater)

After a **green** pilot, declining P-ADM is a decision to return to **open-loop**.

- Convert window: **90 days** post-accept → then mark lost  
- Renewal = **control continuity** (like privileged tooling), not a seat renewal story  
- Expand only on **new order forms**—never free scope into L1  

**Example logo Y1:** $40k + $50k + $25k = **~$115k** + reference rights.

5. Narrow land (FIRST_OFFER)  
6. Expand only on new orders  
7. One concurrent L1  
8. L1 ≠ ARR  
9. Dual + DecisionRecord in every land motion  
10. Walk inventory theater
